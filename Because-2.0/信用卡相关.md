1. c_d_tpc_acct（账户明细表）
字段	说明
data_dt	数据日期（快照），最新 2026-05-31
ab_bal	账户余额（目前振幅余额，单位推测为万元）
acct_type_name	账户类型：人民币账户（44,510条）、融通分期账户（1,702条）、原京东标准卡账户（3,788条）
five_class	五级分类（需进一步确认枚举值分布）
branch_org / org_code	机构标识
cust_id	客户 ID
fin_acct	账户号
2026-05-31 快照共 5 万行，总余额约 1.90 亿（若为万元则 1.90 万亿，需确认单位）。
2. c_d_tpc_card_info（卡片信息表）
字段	说明
data_dt	数据日期，最新 2026-05-31
card_no	卡号
card_status	卡片状态：null（29,191条）、D（20,698条）、L（75条）、O等组合值
open_card_org_no	开卡机构号
cust_id	客户 ID
sleep_card_flag	睡眠卡标识（需确认分布）
注意：distinct_cards=0 说明 card_no 字段当前全部为 NULL 或空，这需要排查数据质量
用户问题
  ↓
1. 维度聚合（c_d_tpc_acct GROUP BY）
   - 按 five_class 汇总 → 关注类/不良占比
   - 按 branch_org 汇总 → 机构排名
   - 按 acct_type_name 汇总 → 产品/账户类型结构
  ↓
2. 多期对比（相同维度，不同 data_dt）
   - 同比：data_dt IN ('2026-05-31', '2025-05-31')
   - 环比：data_dt IN ('2026-05-31', '2026-04-30')
  ↓
3. 明细下钻（加 WHERE 锁定条件）
   - 锁定异常 five_class='2' + branch_org='xxx'
   - 输出 Top N 客户 + 余额
  ↓
4. 交叉验证（c_d_tpc_card_info）
   - 卡片行为 → 睡眠卡率、激活率
